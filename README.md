# 📈 AI Agent for Trading

An autonomous AI trading assistant built with Python FastAPI, Google Gemini API, and Yahoo Finance to deliver real-time financial data and technical recommendations.

## 🚀 Setup Instructions
1. Install backend packages: `python -m pip install -r backend/requirements.txt`
2. Add your `GEMINI_API_KEY` in `backend/.env`.
3. Start backend: `python -m uvicorn backend.main:app --reload`
4. Open `frontend/index.html` in your browser.
